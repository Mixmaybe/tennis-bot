# Офисный настольный теннис — Telegram-бот

## Запуск

1. Скопировать `.env.example` в `.env` и заполнить `BOT_TOKEN` и `ADMIN_IDS`.
2. Установить зависимости (один раз):
   ```
   python -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   ```
3. Запустить: `.venv\Scripts\python.exe bot.py`
4. Написать боту `/qr`: он пришлёт QR-код для печати.

Бот работает, пока запущен процесс. Данные хранятся в `tennis.db` (SQLite), для резервной копии достаточно скопировать этот файл.

## Как устроено

- **Регистрация:** имя, отдел, стаж (дни/месяцы/годы), самооценка. Из них считается рейтинг посева (самооценка ×20 плюс 0..20 за стаж). По рейтингу бот предлагает лигу: Высшую (≥80), Первую (≥45) или Открытую.
- **Турнир:** внутри лиги каждый играет с каждым. Лигу с одним игроком при старте сливают с соседней. Поздние участники получают матчи со всеми игроками своей лиги.
- **Очки по правилам ITTF:** победа 2, поражение 1, неявка 0. При равенстве сравниваются личные встречи, затем соотношение партий, затем соотношение мячей.
- **Счёт:** партия до 11 с разницей в 2, матч до 2 или 3 побед (`BEST_OF`). Считать можно вживую кнопками «+1» (бот следит за подачей) или ввести готовый счёт текстом.
- **Подтверждение:** турнирный результат подтверждает выбранный судья или любой админ, но не участник матча. Дружескую игру подтверждает соперник.
- **Статусы:** «готов сейчас / через 5 / 30 / 60 минут», «жду приглашения». Статус сбрасывается сам.
- **Стол:** занимается автоматически на время живого счёта или вручную на 15 или 30 минут.

## Файлы

`bot.py` — точка входа, `config.py` — настройки, `db.py` — база, `logic.py` — правила и таблица,
`services.py` — общие операции, `ui.py` — кнопки и тексты, `handlers/` — обработчики.
